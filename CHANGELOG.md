# Changelog

## [1.0.0]

Première version publique, pour Minecraft Horizon 26.3.

- Les infos du joueur visé s'affichent autour de lui :
  - les cœurs au-dessus du pseudo ;
  - le mode de jeu et le ping à côté ;
  - l'armure à gauche ;
  - les objets en main, la posture, l'action, la monture, la distance et les coordonnées à droite ;
  - les derniers événements sous les pieds.
- La ligne de vue est vérifiée : rien à travers les murs, et rien pour les joueurs invisibles. Les spectateurs ne sont visibles que si tu l'es aussi.
- Réglages dans Options > Mods > Players Info.
